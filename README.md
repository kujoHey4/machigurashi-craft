# まちぐらしクラフト（Machigurashi Craft）

自分だけの「街」を育てながら、のんびり暮らす Minecraft の MOD です（Minecraft 26.3 / Fabric）。
家具は 900 種以上。釣り・虫とり・料理・お店・カジノ・ダンジョンまで入っています。

A Japanese-language Fabric mod for a cozy, slow-life town. All in-game text is in Japanese.

## ダウンロード

**[いちばん新しい版（machigurashi-craft.zip）をダウンロード](https://github.com/kujoHey4/machigurashi-craft/releases/latest/download/machigurashi-craft.zip)**　（いまの版: 1.0.1）

zip の中身:

| ファイル | 中身 |
|---|---|
| `cozyfurniture-1.0.1.jar` | 本体（かならず入れます。約 210MB） |
| `machikura_ext-1.0.0.jar` | 拡張パック（入れても入れなくてもよい。約 37MB）。17 テーマの家具・壁紙・床・家の外観 |
| `machikura_pachinko-1.0.0.jar` | パチンコ追加パック（入れても入れなくてもよい。約 27MB）。パチンコ台の機種を 2 つ足します |
| `よんでね.txt` | 入れ方と注意 |

## 入れ方

1. **Fabric を入れる**: <https://fabricmc.net/use/installer/> から「Fabric Installer」をダウンロードして開きます。「クライアント」のまま、Minecraft のバージョンを 26.3、ローダーのバージョンを 0.20.1 以上にして、「インストール」を押します。ランチャーに「fabric-loader-26.3」という起動構成ができます。
2. **Fabric API を入れる**: <https://modrinth.com/mod/fabric-api/versions> から、26.3 用の Fabric API（0.165.0+26.3 で確認）をダウンロードして、`mods` フォルダに入れます。`mods` フォルダは、マイクラのランチャーの「起動構成」で「fabric-loader-26.3」にマウスを合わせ、右に出るフォルダのマークを押すと開くフォルダの中にあります（なければ `mods` という名前のフォルダを作ります）。
3. **この MOD を入れる**: zip を開いて、中の jar を、同じ `mods` フォルダに入れます。
4. **起動する**: ランチャーで「fabric-loader-26.3」を選んで起動し、新しいワールドを作ります。

サーバーで遊ぶときは、サーバーとみんなの両方に、同じ jar を入れてください。

## 前の版から入れかえるとき

1. `mods` フォルダの古い `cozyfurniture-〜.jar` を消して、新しい jar を入れます。
2. `config` フォルダの中の `cozyfurniture` フォルダを消してから起動します（消さないと、新しいお店の品や売値が出ません。街や持ち物は消えません）。

## 注意

- 新しいワールドで始めてください。すでに遊んでいるワールドでは試していません。
- シェーダーを入れた場合は試していません。
- 画面の文字は日本語だけです。
- 容量やメモリが足りないときは、拡張パックだけ外してください。本体だけでも遊べます。
